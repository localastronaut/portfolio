# Archive

Old portfolio pages and assets, kept out of the live site for future rework.

Nothing in here is linked from the live site (`/index.html`, `/how-i-code.html`, `/about.html`). These files reference the old `archive/assets/` (`main.css`, `libs.min.css`, `js/`, `fonts/`, `img/`). Internal links among archived pages mostly still resolve; links back to the live home page do not, since the live site now lives at the repo root with a different design.

Contents:

- `project-*.html`, `projects.html` — old top-level project pages / listing
- `projects/` — individual project case studies
- `explore.html` — a one-off design-direction comparison page
- `assets/` — the old template's CSS, JS, fonts, and images
